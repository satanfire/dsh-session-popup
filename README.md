# dsh-session-popup

给 DeepSeek Harness 补上**页面内弹窗**。

智能体需要你决策时，屏幕中央弹出提示并响一声。任务完成时，右上角弹出卡片，
也会有一个轻提示音。

系统通知只在页面隐藏时出现，解决不了这个问题：**页面就在你面前，你却看不出
有一个会话卡住了。** 本插件把「声音 + 弹窗」做在一起。

## 提醒矩阵

| 情况 | 声音 | 位置 | 消失方式 |
| --- | --- | --- | --- |
| 智能体等你决策（审批、提问） | 三段上行琶音 | 屏幕中央 | 手动关闭：按钮、点遮罩、按 Esc、或「打开会话」 |
| 任务完成（别的会话） | 短促琶音 | 右上角卡片 | 9 秒后自动消失，鼠标悬停时暂停计时 |
| 你正在看的那个会话完成 | 短促琶音 | 不弹 | 只听声音 |
| 你正在看的那个会话等你决策 | 三段上行琶音 | 右上角小角标 | 点击角标跳到会话，提示清除 |

后两行是刻意的：你已经在读那个会话了，再糊一层遮罩只会挡住内容。
完成只留声音，待决策退成小角标，都不挡页面。

## 安装

在 DSH 的插件市场安装，或直接写进 profile 的 `package.json`：

```json
{
  "dependencies": {
    "@satanfire/dsh-session-popup": "https://codeload.github.com/satanfire/dsh-session-popup/tar.gz/<commit-sha>"
  }
}
```

`cordis.patch.yml` 由包内的 bundle patch 自动插入，不需要手动加行。

安装后刷新页面。

## 触发规则

只认**状态边沿**，同一个事件只提醒一次：

- **待决策出现**：`pendingInteraction` 从无到有，或换成了新的一个。
- **任务完成**：`running` 从 `true` 变成非 `true`。

两条补充：

- 页面加载时，**仍处于等待状态**的决策会照常弹出。它确实还在等你。
- 页面加载时，**已完成**的任务不会重播。历史不打扰人。

### 刻意不提示的三种情况

1. **正在看的会话完成了。** 回复就在眼前，再弹一张卡就是噪音。如果不拦，
   每回复一条消息都会冒一次提示。
2. **子智能体（subagent）会话。** 它们是她/它 spawning 出来的内部会话，
   侧边栏本来就不显示。为它们弹「任务完成」只会让人莫名其妙。
   子会话的提示统一由父会话负责。
3. **决策已经被处理。** 你在别处（另一个窗口、另一个标签页）回答了提问，
   弹窗会自动撤回，不会继续等你。

第一、二条只拦「完成」和子会话；其他会话的完成、以及任何会话的决策，照常提示。

## 声音

两个音色都用 Web Audio 现场合成，不带音频文件，不下载任何东西。

- **需要你处理**：三段上行琶音，比完成音更突出。
- **任务完成**：短促的三角波琶音，轻快不刺耳。

浏览器要求先有一次用户手势才允许出声。页面加载后第一次点击或按键会解锁音频，
之后正常播放。解锁之前**不排队补播**，所以不会攒一堆提示音一起爆响。

音量由 `VOLUME_PERCENT` 决定，默认 `40`。

**不再需要 `dsh-plugin-notify-sounds`。** 两者的声音与弹窗完全重复，装一个就够。
本插件只做「声音 + 弹窗」，不接管那个插件的系统通知、标题栏闪烁、重复提醒、
静音时段和自定义音效上传。

## 不做的事

- 不发系统通知（OS 通知）。页面在前台时系统通知本来就不该出现。
- 不做标题栏闪烁、重复提醒、静音时段、自定义音效上传。
- 不提供设置页。行为由 `client.js` 顶部的常量决定，改一行就生效。

## 可调项

打开 `client.js`，文件开头 `//#region tunables` 一节：

| 常量 | 默认值 | 含义 |
| --- | --- | --- |
| `COMPLETION_TTL_MS` | `9000` | 完成卡片停留时长（毫秒） |
| `MAX_COMPLETION_CARDS` | `3` | 完成卡片最多同时堆几个，多出的先丢 |
| `NOTICE_LIMIT` | `40` | 内存里最多保留多少条提示 |
| `DETAIL_MAX` | `220` | 提示正文最长字符数，超出截断 |
| `TITLE_MAX` | `60` | 会话名最长字符数，超出截断 |
| `VOLUME_PERCENT` | `40` | 提示音音量，0–100，0 表示静音 |

音色本身在 `//#region sound` 的 `TONES` 里，每个音是若干振荡器音符
（`freq` 频率、`at` 起始偏移、`dur` 衰减时长、`gain` 相对电平、`type` 波形）。

## 工作原理

两半：

- **Host 半**（`index.js`）不做任何事。它被 Loader 挂载，只是为了让客户端模块
  扫描器读到 `package.json` 里的 `dsh.client`，从而把浏览器代码送进页面。
- **浏览器半**（`client.js`）做全部工作：
  - 订阅 `uiSession.sessionStatus`，用快照差分算出边沿；
  - 边沿到达时先响一声，再决定要不要画出来；
  - 把提示放进一个外部 store；
  - 通过 `useSyncExternalStore` 渲染，挂在 `shell.overlay` 插槽上。

`shell.overlay` 是 DSH 自带的整框浮动层，本身可点击穿透。本插件只让弹窗本身
接收点击，页面其它部分不受影响。

颜色、阴影、圆角全部取主题变量（`--dsw-alias-*` / `--dsw-elevation-*` /
`--dsw-radius-*`），浅色深色自动跟随，不需要两套样式。桌面端会避让标题栏，
不会压住窗口按钮。

弹窗打开时焦点进入弹窗，Tab 不会走到遮罩后面；关闭后焦点回到原来的位置。
右上角卡片出现与消失会通过 `aria-live` 播报给读屏。

## 兼容性

- DeepSeek Harness `>= 0.2.0-rc.2`
- Node `>= 22`
- 只在 Web 端生效

## 卸载

在插件市场停用，或从 profile 的 `package.json` 删除依赖后重新安装。
